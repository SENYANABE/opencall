## Порядок выпуска

1. Сверить финальную версию в ветке, пробный сбор и основания доступа в найденных карточках. Перед стартом проверить доступность двух конкурсов в первой подборке и текущий закреп в Telegram.
2. По согласованию влить обновление в `main`. История изменений остаётся в коммитах и PR. Существующие файлы данных не переносятся поверх серверных.
3. Обновить cron на сервере и перезапустить долгоживущий `opencall-bot`, чтобы он загрузил новый код. Проверить, что используется один активный процесс модерации и один набор задач запуска. Просмотреть старую очередь через `/queue` и оценки старых черновиков через `/drafts`.
4. Сформировать черновики анонса, опроса, подборки и навигации. Редактор сначала выпускает анонс, затем опрос и подборку. При необходимости временно закрепляет анонс, после чего закрепляет навигацию.
5. Публичное название и описание менять только после согласования формулировки. Username остаётся прежним. Пятничный черновик планируется на 4 декабря с 09:00 МСК. При наличии материалов и одобрении он выходит с 10:00.

Для предпросмотра выполнить локальные команды:

```bash
python opencall/formats.py --dry-run --format update --input docs/launch/announcement.json
python opencall/formats.py --dry-run --format poll --input docs/launch/launch-poll.json
python opencall/formats.py --dry-run --format collection --input docs/launch/collection.json
python opencall/formats.py --dry-run --format nav
```

После согласования на сервере заменить `python opencall/formats.py --dry-run` на `deploy/run.sh formats`. Это создаст редакторские черновики. Для выхода в канал редактор нажимает кнопку выпуска.

При неопределённом ответе Telegram сначала открыть канал и проверить, появился ли пост. В журнале `отправляется` или `проверить_отправку` означает, что повтор блокируется до сверки. После сверки редактор технически восстанавливает фактический статус и ссылку либо возвращает материал на модерацию.

## Первый месяц

В текущем отчёте `data/STATS.md` есть объём сбора, причины отбраковки, выпуски по рубрикам, подписчики и просмотры из публичной ленты. После первого рабочего прогона появляются статусы доказанной доступности. Для доли российских конкурсов считать карточки с `geography = Россия` среди новых карточек с установленной географией, отдельно фиксировать неизвестную географию.

Главная метрика — уникальные пользователи, которые подали хотя бы одну заявку через ленту за месяц. Нативный опрос измеряет число добровольно ответивших и распределение среди них. Указывать число голосов и период, сохранять формулировку вопроса для сравнения. Просмотры, пересылки, реакции и переходы учитывать там, где доступны исходные данные. Поиск и внешние упоминания измерять по [протоколу](../seo-geo.md#повторный-замер).
